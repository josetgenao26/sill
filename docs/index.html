01 / The problem

Cmd+Tab collapses every window of an app into a single icon.

Three projects open in the same editor, and macOS treats them as one destination — it drops you in whichever one it feels like. Sill lists those three windows as three separate entries, ordered by how recently you used them.

04 / Install
01

Download the latest release, unzip it, and move Sill.app to /Applications.

02

Right-click the app, choose Open, and confirm.

macOS will block the first launch. Sill is signed with a self-signed certificate, not a paid Apple Developer ID, so Gatekeeper refuses it on a plain double-click. Right-click → Open gets past it. Once, on the first run.

03

Grant Accessibility permission when Sill asks. It needs it to read and raise other apps' windows.

04

Turn on Start at Login from the menu bar item. There's no Dock icon and no main window — the menu bar is the whole interface.

05 / Limits

Sill uses no private macOS APIs. That has a price, and here it is.

Sill does not list windows on other Spaces, and it cannot switch Spaces. Those are limits of the public APIs it is built on — not features waiting on a roadmap.

If you live across several Spaces, this is the thing to know before you download.
